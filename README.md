## ✨ Overview

RXFoxyVPN is a cross-platform project for **Android and Windows**. This repository contains the project source code and documentation; ready-to-use builds, when published, are available from the GitHub Releases page.

## 🚀 Highlights

- **Two platforms** — Android and Windows.
- **Multilingual interface** — includes English, Persian, Russian, Simplified Chinese, Korean, and Arabic.
- **Android VPN service** — use the Android app to manage a VPN connection.
- **Windows desktop interface** — with system-tray integration.
- **Source available** — inspect the code and follow development through GitHub.

## 📥 Download

Visit **[GitHub Releases](https://github.com/omidrx0/RxFoxyVPN/releases/latest)** for available builds.

- **Android:** download the APK asset provided in the release.
- **Windows:** download the portable EXE or ZIP package provided in the release.
- **Source code:** use the repository link above.


## 📥 Clone the repository

```bash
git clone https://github.com/omidrx0/RxFoxyVPN.git
cd RxFoxyVPN
```

## 🧑‍💻 Project structure

```text
Android/    Android application (Kotlin / Gradle)
Windows/    Windows application (Python / web UI)
docs/       Translated README files
```

## 🛠️ Development

- **Android:** open the `Android/` directory in Android Studio and check the project Gradle configuration for the required JDK and Android SDK versions.
- **Windows:** review the source and packaging scripts under `Windows/` and install dependencies listed by the project before running or packaging the app.

Build steps can vary by project configuration and environment; use the configuration files in the repository as the source of truth.
