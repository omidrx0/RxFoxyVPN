## 📥 다운로드
[최신 릴리스 페이지](https://github.com/omidrx0/RxFoxyVPN/releases/latest)에서 기기에 맞는 파일을 선택하세요. 릴리스에 따라 Android APK와 Windows EXE 또는 ZIP 파일이 제공될 수 있습니다.

## 🧰 소스 코드
```bash
git clone https://github.com/omidrx0/RxFoxyVPN.git
```
Android 프로젝트는 Android Studio에서 여세요. Windows 빌드 전 Windows 폴더의 소스 코드와 패키징 안내를 확인하세요.

## 🔐 보안 및 라이선스
비밀번호, 서명 키, 개인 설정을 커밋하지 마세요. 재배포 전 타사 구성 요소의 라이선스를 확인하세요. 저장소에 라이선스 파일이 추가되기 전에는 코드 재사용이 제한 없이 허용된다고 가정하지 마세요.
