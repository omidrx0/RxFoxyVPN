## ✨ 주요 기능

- Android 및 Windows 지원.
- 영어, 페르시아어, 러시아어, 중국어 간체, 한국어, 아랍어 인터페이스.
- Android VPN 서비스와 시스템 트레이 통합을 지원하는 Windows 데스크톱 UI.
- 저장소에서 소스 코드와 문서를 확인할 수 있습니다.
