## امکانات

برنامه اندروید و ویندوز؛ رابط کاربری به زبان‌های انگلیسی، فارسی، روسی، چینی ساده‌شده، کره‌ای و عربی؛ سرویس VPN اندروید؛ رابط دسکتاپ و آیکون کنار ساعت ویندوز.

## ساختار پروژه

```text
Android/    Android application (Kotlin / Gradle)
Windows/    Windows application (Python / web UI)
docs/       Translated README files
```

## شروع کار

مخزن را Clone کنید. پوشه `Android/` را در Android Studio باز کنید. برای ویندوز، کدها و اسکریپت‌های بسته‌بندی `Windows/` را بررسی کنید، وابستگی‌های پایتون را نصب کنید و از مسیر مناسب برنامه دستور `python -m rxvpn` را اجرا کنید. ممکن است تنظیمات و ابزارهای جانبی دیگری لازم باشند.

```bash
git clone https://github.com/YOUR_USERNAME/RXFoxyVPN.git
```
