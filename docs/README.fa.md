## معرفی

RXFoxyVPN پروژه‌ای چندسکویی برای **اندروید** و **ویندوز** است که رابط کاربری ساده و یکپارچه‌ای به زبان شما ارائه می‌دهد. این مخزن شامل سورس‌کد و مستندات است؛ نسخه‌های آماده در صفحهٔ [Releases گیت‌هاب](https://github.com/omidrx0/RxFoxyVPN/releases/latest) منتشر می‌شوند.

### تغییرات نسخهٔ 1.0.3

در این نسخه، فرایند ورود به Firefox Accounts در ویندوز بهبود یافته و تغییراتی در احراز هویت، سازگاری HTTP، مدیریت کوکی‌ها و Challenge و تأیید حساب انجام شده است. هدف این تغییرات کاهش مشکلاتی است که ممکن است باعث خطای `406 Not Acceptable` شوند.

**وضعیت تست:** تست‌های HAWK، PBKDF2/HKDF و بررسی `gofmt` موفق بودند. Build کامل ویندوز و تست ورود واقعی هنوز انجام نشده‌اند؛ بنابراین رفع قطعی خطای 406 تأیید نشده است.

## ویژگی‌ها

| اندروید | ویندوز |
| --- | --- |
| سرویس VPN بومی برای مدیریت اتصال | رابط دسکتاپ همراه با یکپارچگی با System Tray |
| صفحه‌های اصلی، فهرست سرورها و تنظیمات | رابط کاربری مبتنی بر وب در قالب برنامهٔ دسکتاپ |
| پشتیبانی از اندروید ۸٫۰ و بالاتر | حالت TUN سراسری و پشتیبانی از پروکسی سیستم |

**هر دو پلتفرم:** رابط کاربری به زبان‌های انگلیسی، فارسی، روسی، چینی ساده‌شده، کره‌ای و عربی.

## ساخت از روی سورس

<details>
<summary>نمایش مراحل ساخت</summary>

<br>

مخزن را کلون کنید:

<div dir="ltr">

```bash
git clone https://github.com/omidrx0/RxFoxyVPN.git
cd RxFoxyVPN
```

</div>

- **اندروید:** پوشهٔ `Android/` را در Android Studio باز کنید، صبر کنید Gradle همگام‌سازی شود (نسخه‌های موردنیاز JDK و Android SDK را در فایل‌های Gradle ببینید) و سپس برنامه را اجرا کنید یا از *Build → Build APK(s)* استفاده کنید.
- **ویندوز:** نسخهٔ جدید برنامه با Go نوشته شده است. سورس‌کد و دستورالعمل‌های ساخت نسخهٔ ویندوز را در مخزن دنبال کنید و پیش‌نیازهای Go و رابط وب را مطابق تنظیمات پروژه آماده کنید.

مراحل ساخت ممکن است بسته به محیط شما متفاوت باشد؛ فایل‌های پیکربندی مخزن مرجع اصلی هستند.
